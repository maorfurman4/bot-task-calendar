# ✅ יוסי — משימות ליומן

בוט טלגרם שמכניס ליומן משימות, אירועים ומשמרות. עונה מיד (webhook ב-Vercel: https://yossi-bot.vercel.app).

## איך משתמשים
- **טקסט חופשי**, למשל "לקנות חלב, אימון מחר ב-6 בבוקר": יוסי מציג קודם בדיוק מה ייכנס — יום, תאריך ושעה —
  ומכניס רק אחרי "✅ הוסף":
  - משימה בלי שעה → Google Tasks
  - אירוע עם שעה → Google Calendar (שעה כברירת מחדל, תזכורת 30 דק' לפני)
- **ביטול מהיומן**: "בטל לי את הנדסת חשמל מחר" / "תמחק את הפגישה עם דני" → יוסי מחפש ביומן הראשי (ביום שנאמר,
  או בשבועיים הקרובים), מציג את האירועים שמצא ומוחק רק אחרי "🗑️". בשיעור קבוע נמחק רק המופע של אותו יום.
  לא מצא — אומר את זה, ולא מוסיף משימה.
- **הודעה קולית** — מתומללת (gpt-4o-transcribe, ואם לא זמין whisper-1) ומטופלת כמו טקסט.
- **צילום מסך** של הזמנה/תור/כרטיס/SMS — יוסי מציג את האירועים והמשימות שמצא ומוסיף אחרי "✅ הוסף".
- **↩️ ביטול**: אחרי כל הוספה (טקסט, הקלטה, צילום מסך) יש כפתור שמסיר בדיוק את מה שנוסף
  (אירועים מסומנים ב-`yossi_batch`, משימות בהערה `yossi:<מזהה>`). משמרות מוחלפות ע"י שליחה מחדש, בלי כפתור ביטול.
- **משמרות בקיצור** — הדרך האמינה: "משמרת צהריים בראשון שלישי וחמישי, שבת לילה רמש".
  חייב להופיע "משמרת". ברירת מחדל — השבוע הבא (ביום ראשון: השבוע הנוכחי); "השבוע"/"שבוע הבא" גוברים.
  "רמש" = רמ"ש, "12" = משמרת 12 שעות. יוסי מציג את המשמרות, מה השתנה מהסידור שכבר ביומן והתנגשויות —
  ומכניס ליומן רק אחרי "✅ אשר". שליחה מחדש לאותו שבוע מחליפה את המשמרות (מסומנות ב-`yossi=shift`).
- **תמונה של סידור עבודה** — ניסיוני: הטבלה צפופה מדי והשמות קטנים, אז הקריאה לא אמינה (נבדק 24/10/2026).
  כשהשם לא נמצא, יוסי מציע לכתוב בקיצור.

## שעות המשמרות (`api/_shifts.py`)
| עמדה | בוקר | צהריים | לילה |
|---|---|---|---|
| רגילה | 07:00–15:00 | 15:00–23:00 | 23:00–07:00 |
| רמ"ש (שעה מוקדם) | 06:00–14:00 | 14:00–22:00 | 22:00–06:00 |
| יום עם 12/12 באדום | 07:00–19:00 | — | 19:00–07:00 (רמ"ש: שעה מוקדם) |
| שורה עם שעות בשם (שיפוצים 7:00-17:00) | לפי השעות בשורה | | |

ה-AI (gpt-5, ואם לא זמין gpt-4o) רק מאתר את התאים עם השם; את השעות מחשב הקוד.

## קבצים
| קובץ | תפקיד |
|---|---|
| `api/webhook.py` | נקודת הכניסה — מקבל הודעות מטלגרם |
| `api/_core.py` | טלגרם, AI, Google, טקסט חופשי → משימות ואירועים |
| `api/_shifts.py` | משמרות (קיצור טקסט ותמונה) וצילומי מסך → אירועים |
| `test_yossi.py` | בדיקות: `python test_yossi.py` |
| `pyproject.toml` | ספריות + הגדרת Vercel |
| `.github/workflows/deploy.yml` | מעתיק סודות ל-Vercel, מעלה ומחבר את טלגרם (הרצה ידנית) |

## סודות (Settings → Secrets → Actions)
`VERCEL_TOKEN`, `TELEGRAM_TOKEN`, `CHAT_ID`, `OPEN_API_KEY`, `GOOGLE_SERVICE_ACCOUNT_JSON`, `GOOGLE_TASKS_CREDENTIALS`

כל push ל-main מעלה גרסה חדשה ל-Vercel אוטומטית. אחרי שינוי סוד — להריץ שוב את `deploy.yml`.
